# Editor Waveform

Shows the current song's waveform and spectrogram directly on the Geometry Dash editor grid.

## Notes

- Works with built-in and downloaded main songs, including during playtesting.
- Adjust appearance in Geode settings or Eclipse's Editor Waveform → Settings panel.
- Toggle each display independently. Spectrogram controls include position, height,
  opacity, FFT window size, frequency borders, gradual linear/log spacing, and colors.
- Long songs retain full coverage with reduced spectrogram timing detail when needed.
- Song and offset changes update automatically.
- Classic levels only; Song/SFX triggers are not included.
- [Original demonstration](https://youtu.be/sE_xLYuiZm8).
